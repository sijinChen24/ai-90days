## 已解决

- [x] 为什么终端敲 `python` 提示 `command not found`？
      → macOS 上 python.org 的安装包**故意只建 `python3`**，不建裸 `python`（历史上 `python` 指向 Python 2）。
      全局用 `python3`，虚拟环境激活后才有 `python`。
- [x] 为什么 `jupyter` 也 command not found？
      → 当时 Jupyter 装在项目 venv 里，而 venv **没激活**。已改为全局安装，任意目录可直接敲。
- [x] `git push` 报 `Permission denied (publickey)`？
      → GitHub 上没有本机公钥。生成 `ssh-ed25519` 并加到 GitHub → Settings → SSH and GPG keys。
- [x] `git commit` 报 `index.lock` 已存在？
      → 有别的进程（Qoder）在同时跑 git。**一个仓库只开一个 IDE**；确认无进程持有时可 `rm -f .git/index.lock`。
